เว็บไซต์เซอร์ไพรส์: ขอจีบได้มั้ย ♡

วิธีเปิดดู:
1) แตกไฟล์ ZIP
2) เปิดโฟลเดอร์ love_site
3) ดับเบิลคลิก index.html

วิธีเผยแพร่ให้แฟนเปิดผ่านลิงก์:
- เข้า https://app.netlify.com/drop
- ลากโฟลเดอร์ love_site (หรือ ZIP ที่แตกแล้ว) ไปวาง
- Netlify จะสร้างลิงก์เว็บไซต์ให้ นำลิงก์นั้นส่งให้แฟนได้เลย

หมายเหตุ:
- หน้าเว็บทำงานบนมือถือและคอมพิวเตอร์
- ปุ่ม “ไม่ให้จีบ” จะหนีเมาส์/นิ้ว และเปลี่ยนข้อความแซว
- ปุ่มสีชมพูจะพาไปหน้าขอบคุณ
- Google Fonts ต้องใช้อินเทอร์เน็ตเพื่อโหลดฟอนต์; ถ้าไม่พร้อมจะใช้ฟอนต์สำรอง
